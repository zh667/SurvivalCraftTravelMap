# 旅行地图 v2.9.0

三项改动，联机版 `.netmod` 和插件版 `.scmod` 同步。

## 地形明暗方向修正

玩家反馈（插件版截图）：大坑看着像凸起的土包，建筑物中间凹进去的部分看着像凸出来。

原因：地形明暗是 7 月按“光从世界 −X / −Z 方向来”写的；7 月 24 日修“东南西北全反”时把整张地图平面转了 180°（世界 +X 画在屏幕左边、+Z 画在上边），光照没有跟着转，于是在屏幕上光变成从**右下方**来。人眼默认光从左上来，所以凹凸看反。

- 现在光从世界 +X / +Z 一侧来，固定北方朝上时就是屏幕左上方：凸起的东西左上边亮、右下边暗，坑的左上内壁暗、右下内壁亮。
- “行进方向朝上”模式下明暗是烘在地图像素里的，会跟着地图一起转（与以前一样）。
- **老区域**：地图只存每格的明暗值，不存高度，旧数据没法精确重算。升级后先把旧明暗按中性值翻转（亮变暗、暗变亮）近似显示，并把旧瓦片里所有探索过的区块标成“待重录”；玩家走到附近、区块加载时会按新算法重新记录一次，记录完标记清除。重录前，单格的小坑、小尖的额外加减会被翻反，影响很小。
- 洞穴模式的明暗表示高低（不是光照），不翻转、不重录。
- 存档格式升级：新数据写入 `x_z.v5.sctm`；2.8.0 的 `x_z.v4.sctm` 和更早的 `x_z.sctm` 只读不改。退回 2.8.0 时不会把新文件当成损坏，只是看不到升级后新探索、重录的部分。

## 生物标记四色

玩家建议按“会不会打你”分四色。颜色看态度，大小看体型：

| 颜色 | 含义 | 判断（按顺序，先中先定） |
|---|---|---|
| 红 | 已经在追你 | 此刻追击目标是玩家；或已知模组敌人（CS 武器的匪 `ComponentTacticalEnemy`、机甲防线的机兵 `ComponentMDRobot`，看不出是否在追，一律红） |
| 蓝 | 友方或已驯服 | CS 武器的队友、人质（`ComponentTacticalCompanion`）；或装了鞍的坐骑（模板名以 `_Saddled` 结尾，游戏自己也是这样区分的） |
| 黄 | 会追但还没追 | 游戏原版的追击行为满足任一：主动追击范围大于 0、碰到就冲的概率大于 0、被打还手的概率不低于 50%；或类别是捕食者。插件版里被模组设成“不打玩家”的追击行为，范围和碰撞两条不算 |
| 绿 | 不会追 | 其余 |

- 体型：水生＝鱼，会飞＝鸟，其余＝陆地。鸟和鱼按 60% 大小画，颜色规则相同；红色标记 125%。
- “显示鸟类”“显示鱼类”开关按体型判断。
- 友方此刻在追玩家时显示红色（与 2.8.0 一致）。
- 去掉 2.8.0 的鸟黄、鱼青两色。

原版生物举例（两版游戏数据核对过，数值相同）：

| 生物 | 白天/夜里主动追击范围 | 碰到就冲 | 被打还手 | 标记 |
|---|---|---|---|---|
| 狼 | 4 / 10 | 1 | 1 | 黄（发现你后红） |
| 犀牛 | 16 / 16 | 1 | 1 | 黄 |
| 公牛 | 1.5 / 1.5 | 0.5 | 1 | 黄 |
| 母牛 | 0 / 0 | 0 | 0.1 | 绿 |
| 骆驼 | 0 / 0 | 0 | 0.2 | 绿 |
| 鞍马 | 无追击行为 | | | 蓝 |
| 鸽子 | 无追击行为 | | | 绿（小） |
| 公牛鲨 | 8 / 16 | 1 | 1 | 黄（小） |

其他模组的友方、驯服生物只认得上面列出的几种；认不出来的按原版追击参数归类。

### 认得出名单外的模组敌人

名单之外的模组生物（例如尸鬼模组那颗会射击的头颅：没有原版追击行为）以前只能按原版追击参数归类，常常成了绿色。现在再看两样行为：

- **盯着玩家**：生物任何一个组件里，类型是生物或身体、名字带 target / prey / victim 的字段（含非公开字段）此刻指向玩家，就显示红色。每种组件只反射一次字段列表并缓存，每帧只读这些字段。游戏原版的“躲开玩家、盯着看、跟随、走开、被召唤”等行为也会把玩家放在 m_target 里，所以原版组件里只看追击行为的字段。
- **打过玩家**：玩家受伤时取攻击者（弹射物取发射者）。这只生物 10 秒内显示红色；它的模板名记进本世界地图缓存目录里的 `hostile-templates.txt`，之后同类没在追时显示黄色（本来是绿色的才会变黄；蓝色友方保持蓝色）。
- 名单（CS 的匪、机甲防线的机兵、CS 的队友和人质）保留为覆盖项；友方和装鞍坐骑仍是蓝色，但盯着玩家或刚打过玩家时显示红色。

## 两份游戏的同名世界不再共用地图缓存

以前地图缓存按游戏给的世界目录名（如 `app:/Worlds/World1`）区分，不含安装路径：同一台电脑上两份游戏（或测试副本）里同名的世界共用一个缓存目录，种子不同就被“世界重名保护”清空，换着玩就丢图。

- 本地世界改按世界文件夹的**完整系统路径**区分（统一分隔符、去掉结尾分隔符、不分大小写）。拿不到系统路径时仍用旧的目录名。联机服务器的世界不变。
- 升级时，新位置还没有缓存、旧位置的缓存又属于这个世界（种子相同），就把旧缓存**复制**过来（先复制到临时目录再改名）；旧目录原样保留，退回旧版本时还在。旧缓存种子不同（属于另一份游戏里同名的世界）就不动它，也不清空它。
- 新位置照样有世界重名保护。

## 验证

隔离游戏副本实测（用户本机游戏本体的复制品，静音、隐藏窗口；测试模组把 `data:/` 重定向进副本，每次运行前后只读比对 `%LOCALAPPDATA%\Survivalcraft\SurvivalcraftTravelMap` 下 17829 个文件的大小和修改时间，全部没变）：

- 明暗方向：平坦世界里垒 5×5、3 格高的台，挖 5×5、3 格深的坑，按大地图截图像素（3×3 平均亮度）比较。台的屏幕左上邻格比右下亮，坑的左上内壁比右下暗，地图数据与按地形现算的一致。插件版 1.9.3.1（台 左 148.8 / 右 93.1，坑 左 90.8 / 右 144.4）、1.9.5.1（146.8 / 89.5，87.1 / 141.9）、联机版（133.4 / 69.2，66.9 / 128.6）全部通过。
- 旧存档 + 缓存迁移：
  - 插件版 1.9.3.1、1.9.5.1：2.8.0 包建台和坑并存档（复现反光：台左上暗、右下亮），2.9.0 包打开。地图缓存从旧键目录复制到按完整路径的新键（两份副本同名世界的旧键相同，新键不同），旧键下 15 个 `.v4` 文件不变；走近前显示翻转后的旧值、方向已对，区块待重录；走近后重录为新值。
  - 联机版：用当前包建图，测试把缓存挪回旧键目录代替旧版本，再打开：缓存复制到新键，离玩家 400 格的场地不经重录就显示原来的明暗，旧键文件不变。
- 生物标记：狼、公牛、鲨鱼＝黄，母牛、骆驼、野马、鸽子、鲈鱼＝绿，鞍马＝蓝（三个运行时一致）；CS 武器 1.5.3：匪＝红，队友、人质＝蓝；尸鬼 2.0.1：尸鬼＝黄，单独刷出的尸化头颅＝绿。
- 打过玩家：挑衅一头母牛让它（经游戏原版追击行为）撞玩家、再用一头骆驼当发射者朝玩家射箭；两者打中后立刻显示红色，模板写进本世界缓存的 `hostile-templates.txt`，之后远处同类显示黄色。联机版、插件版 1.9.3.1、1.9.5.1 全部通过（箭能追到发射者）。
- 尸鬼模组的尸化头颅：它是 Tartareosity 维度里首领的一部分，单独刷出时没有身体会自己消失，没能在测试里让它真的打玩家。读模组代码：首领的近战伤害和弹射物都以头颅为攻击者/发射者，所以打中玩家后头颅会变红、之后同类显示黄色；但首领瞄准玩家时，目标字段在不是生物的身体实体上，头颅本身在打中之前仍是绿色。**未实测。**
- 单元测试 1073/1073 通过；联机包通过 `Verify-Package.ps1`。两个发布包与隔离测试所用的包逐字节相同。

## 发布文件

- 插件版：`[API1.9]TravelMap2.9.0.scmod`
