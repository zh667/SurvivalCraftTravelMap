# 旅行地图 v2.7.1

修复 PC 战斗时按攻击键偶尔自动打开大地图的问题。小地图此前会用隐藏鼠标保留的坐标检测原始左键输入，导致攻击被误判为点击小地图或死亡标记；现在仅在鼠标光标可见时接收原始鼠标点击和滚轮缩放。

- 联机版 `.netmod` 和插件版 `.scmod` 同步修复。
- `M` 键开关大地图、可见鼠标点击、触屏轻触和死亡标记定位保持可用。
- 隐藏鼠标时的滚轮保留给游戏切换物品，地图不再吞掉这类输入。
- 模组名称、作者 `zh667`、包名、API 和游戏兼容声明均沿用 2.7.0；模组版本更新为 2.7.1。

发布文件名沿用版本前缀格式：

- 插件版：`[API1.9]TravelMap2.7.1.scmod`
- 联机版：`[NET]TravelMap2.7.1.netmod`

退出游戏后，用对应版本的新包替换旧地图包，避免同时保留两个版本。`.netmod` 放入 `NetMods`，`.scmod` 放入 `Mods`。无需删除地图缓存、探索记录或坐标点。

回归测试直接驱动两种游戏 API 的小地图组件，覆盖隐藏光标连续攻击、有/无死亡标记、可见光标点击、滚轮、无鼠标光标的触屏手势以及模态输入阻塞。游戏内还需确认：战斗连续点击及切物品不会开图，按 `M` 仍可正常开关大地图。

验证结果：联机版 Release 全量测试 972/972 通过，插件版输入回归测试 9/9 通过；联机包通过 `Verify-Package.ps1`，两包的全部文件均与构建输出/源资产逐项 SHA-256 一致。已确认除 `Version` 外的模组信息与 2.7.0 相同。移除修复后，连续攻击和隐藏鼠标滚轮的 3 个回归用例失败，恢复修复后全部通过。
