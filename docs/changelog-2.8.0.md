旅行地图 Survivalcraft Travel Map —— 持久化探索地图、洞穴投影、坐标点、死亡标记、安全传送、日夜/地形明暗与手机触屏支持。联机版与插件版同仓库、共用地图核心。

## 下载

- **联机版**：`NET.TravelMap2.8.0.netmod` → 放进游戏 `NetMods/` 文件夹。
- **插件版（API 1.9）**：`API1.9.TravelMap2.8.0.scmod` → 放进 `Mods/` 文件夹。

替换旧地图包即可，不要同时保留两个版本；无需删除地图缓存、探索记录或坐标点。

## 本次更新（v2.8.0）

- **已探索区域的冰雪跟着季节变化**：冬天走过的地方到了夏天会自动显示化雪，不用再跑回去刷新。插件版会同时预测积雪；联机版本体加载区块时不会新积雪，所以只预测融化。水面新结冰不做预测（游戏结冰带随机性）。旧版本探索过的区域路过一次后自动补上季节数据。
- **修复手机大地图缩放卡死**：点“保存当前位置”等弹出键盘的操作后，缩放、拖动、长按传送不再失效。
- **生物标记按“会不会打你”分类**：敌对红色（大一号）、友方蓝色、动物绿色、鸟黄色（小）、鱼青色（小）。修正尸鬼模组的怪、CS 武器的匪/队友等被显示成鸟或动物的问题。
- **新增“显示鸟类”“显示鱼类”开关**，默认开。
- **修复 PC 战斗时按攻击键偶尔自动打开大地图**（原 2.7.1 的修复，此前未在 GitHub 发布）。

## 兼容性

- 联机版面向 NetMod API `1.44`、`ScVersion 2.4.40.6`；插件版面向 Survivalcraft API `1.9.2.1` 及以上。
- 地图数据改存为新文件 `x_z.v4.sctm`，旧文件 `x_z.sctm` 原样保留：退回旧版本不会丢图，只是看不到升级后新探索的部分。

功能与安装详情见 [README](https://github.com/zh667/SurvivalCraftTravelMap#readme)。
