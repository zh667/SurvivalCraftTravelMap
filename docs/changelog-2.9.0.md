旅行地图 Survivalcraft Travel Map —— 持久化探索地图、洞穴投影、坐标点、死亡标记、安全传送、日夜/地形明暗与手机触屏支持。联机版与插件版同仓库、共用地图核心。

## 下载

- **联机版**：`NET.TravelMap2.9.0.netmod` → 放进游戏 `NetMods/` 文件夹。
- **插件版（API 1.9）**：`API1.9.TravelMap2.9.0.scmod` → 放进 `Mods/` 文件夹。

替换旧地图包即可，不要同时保留两个版本；无需删除地图缓存、探索记录或坐标点。

## 本次更新（v2.9.0）

- **修复地形明暗看反**：以前光从屏幕右下方来，大坑看着像土包、建筑中间凹进去的地方看着像凸出来。现在光从左上方来（固定北方朝上时）。**老区域先近似显示，走近后自动按新算法重录**，不用删图。
- **生物标记改成四色**：红＝正在追你（或模组敌人），黄＝会追但还没追（没发现你的狼、公牛、鲨鱼），绿＝不会追（母牛、骆驼、鸽子），蓝＝友方或已驯服（CS 队友、装了鞍的坐骑）。鸟和鱼颜色规则相同，画小一号；不再单独用黄色表示鸟、青色表示鱼。不在名单里的模组生物按行为判断：正盯着你、或刚打中你（弹射物算发射者）就显示红色，打过你的种类之后显示黄色（按世界记住）。

- **修复两份游戏共用地图缓存被清空**：以前地图缓存只按世界文件夹名（如 `World1`）区分，电脑上装了两份游戏（或测试副本）时同名世界共用一份缓存，换着玩就会被清空。现在按世界文件夹的完整路径区分；升级时属于本世界的旧缓存自动复制过来，旧缓存保留。

## 兼容性

- 联机版面向 NetMod API `1.44`、`ScVersion 2.4.40.6`；插件版面向 Survivalcraft API `1.9.2.1` 及以上。
- 地图缓存目录按世界文件夹完整路径重新命名，旧目录保留。
- 地图数据改存为新文件 `x_z.v5.sctm`，2.8.0 的 `x_z.v4.sctm` 和更早的 `x_z.sctm` 原样保留：退回旧版本不会丢图，只是看不到升级后新探索的部分。

功能与安装详情见 [README](https://github.com/zh667/SurvivalCraftTravelMap#readme)。
