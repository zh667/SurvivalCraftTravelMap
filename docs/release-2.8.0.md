# 旅行地图 v2.8.0

两项修复，联机版 `.netmod` 和插件版 `.scmod` 同步。

## 远处已探索区域的冰雪跟着季节变化

以前地图只记录探索那一刻的样子：冬天走过的地方，到了夏天地图上还是雪，要亲自回去一趟才会更新。现在地图按游戏自己的冰雪规则推算每个已探索地点“现在回去会看到什么”，季节一变全图跟着变，不用跑回去。

- 游戏只在区块加载时决定积雪或融化（地形温度 + 季节温度 + 高度），地图用同一条规则推算。插件版和联机版的季节温度算法不同（插件版在 0 截断），各按各的游戏算。
- 陆地积雪、融雪，冰面融化都会预测。水面新结冰不预测：游戏加载时结冰带随机性，实测只有约一半水面会冻上，所以新结的冰要看到过才显示。
- 旧版本探索过的区域没有季节数据，路过一次（进入视距）后会自动补上。
- 存档格式升级：新数据写入 `x_z.v4.sctm`，旧的 `x_z.sctm` 原样保留。退回旧版本时不会把地图当成损坏文件，只是看不到升级后新探索的部分。
- 季节温度每变一度（默认一年约 48 次）地图重画一次，旧画面保留到新颜色画好为止，不会闪。

## 大地图缩放卡死（手机）

在大地图里点“保存当前位置”等会弹出键盘的操作后，缩放、拖动、长按传送全部失效，只有设置按钮能点。原因是游戏引擎在键盘弹出或窗口失焦时会丢掉“手指抬起”事件，屏幕上留下一个永远不抬起的触点，地图一直在等“所有手指松开”。现在只有在地图区域内按下的手指才参与地图手势，按钮上留下的触点不再影响缩放和拖动。

## 验证

隔离游戏副本实测（用户本机的游戏本体复制品，不碰原游戏和存档）：

- 季节：冬天记录一片区域，飞到 3000 格外让它卸载，切到夏天看地图预测，再回去与实际地面逐格比对；再从夏天切回冬天重复一次。插件版 1.9.3.1：夏天 11664/11664 格一致，冬天陆地 5386/5386 格一致；插件版 1.9.5.1（单独及加装遗迹模组 2.2.0）同样夏天全部一致、冬天陆地全部一致。
- 触屏：往引擎触点列表里放一个不抬起的触点，再模拟拖动、双指缩放、缩放后再拖动、长按。新版在插件版 1.9.3.1、1.9.5.1 全部通过；旧版 2.7.1 复现卡死（第一次拖动后手势停在“等待全部松开”）。
- 帧时间（电脑）：换季前后中位数约 6.9 ms，99% 的帧 ≤ 9.5 ms。
- 单元测试 994/994 通过。

## 发布文件

- 插件版：`[API1.9]TravelMap2.8.0.scmod`
- 联机版：`[NET]TravelMap2.8.0.netmod`

退出游戏后用新包替换旧地图包，不要同时保留两个版本。`.netmod` 放入 `NetMods`，`.scmod` 放入 `Mods`。不需要删除地图缓存、探索记录或坐标点。
