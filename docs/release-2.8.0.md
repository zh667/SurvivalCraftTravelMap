# 旅行地图 v2.8.0

三项改动，联机版 `.netmod` 和插件版 `.scmod` 同步。

## 远处已探索区域的冰雪跟着季节变化

以前地图只记录探索那一刻的样子：冬天走过的地方，到了夏天地图上还是雪，要亲自回去一趟才会更新。现在地图按游戏自己的冰雪规则推算每个已探索地点“现在回去会看到什么”，季节一变全图跟着变，不用跑回去。

- 插件版：游戏在区块加载时决定积雪或融化（地形温度 + 季节温度 + 高度），地图用同一条规则推算，陆地积雪、融雪、冰面融化都会预测。季节温度按插件版自己的算法（在 0 截断）。
- 联机版：游戏本体（x26.07.01.01）在区块加载时不跑这一步（`ChunkInitialized` 声明了但从不触发），没加载的地方不会新积雪，回去后只会被后台扫描慢慢化掉。所以联机版地图只预测“雪和冰会化”，不预测新积雪，看到过的雪在转冷时照样显示。
- 两个版本都不预测水面新结冰：插件版加载时结冰带随机性，实测只有约一半水面会冻上，所以新结的冰要看到过才显示。
- 旧版本探索过的区域没有季节数据，路过一次（进入视距）后会自动补上。
- 存档格式升级：新数据写入 `x_z.v4.sctm`，旧的 `x_z.sctm` 原样保留。退回旧版本时不会把地图当成损坏文件，只是看不到升级后新探索的部分。
- 季节温度每变一度（默认一年约 48 次）地图重画一次，旧画面保留到新颜色画好为止，不会闪。

## 大地图缩放卡死（手机）

在大地图里点“保存当前位置”等会弹出键盘的操作后，缩放、拖动、长按传送全部失效，只有设置按钮能点。原因是游戏引擎在键盘弹出或窗口失焦时会丢掉“手指抬起”事件，屏幕上留下一个永远不抬起的触点，地图一直在等“所有手指松开”。现在只有在地图区域内按下的手指才参与地图手势，按钮上留下的触点不再影响缩放和拖动。

## 生物标记按“会不会打你”分类，适配更多模组

以前标记颜色只看游戏里的生物类别，很多模组填得很随意：尸鬼模组把所有尸鬼（包括会射击的尸化头颅）登记成鸟类，美好时代的蝴蝶、蝗虫、蝙蝠也是鸟类，CS 武器的匪、队友、人质都登记成“陆地其他”。现在按行为分：

| 标记 | 颜色 | 大小 | 判断 |
|---|---|---|---|
| 敌对 | 红 | 125% | 会主动追打玩家（游戏原版的追击行为）、捕食者、此刻正在追玩家，或已知的模组敌人（CS 的匪、机甲防线的机兵） |
| 友方 | 蓝 | 100% | CS 的队友、人质（正在追玩家时仍显示敌对） |
| 动物 | 绿 | 100% | 其余陆地生物 |
| 鸟 | 黄 | 60% | 会飞、不敌对 |
| 鱼 | 青 | 60% | 水生、不敌对 |

- 设置里新增“显示鸟类”“显示鱼类”，默认开，在“显示生物标记”下面。
- 炮台等不是生物的东西不上地图（和以前一样）。
- 每个生物只判断一次并缓存，每帧只多一次“是否正在追玩家”的检查。

## 验证

隔离游戏副本实测（用户本机的游戏本体复制品，不碰原游戏和存档）：

- 季节：冬天记录一片区域，飞到 3000 格外让它卸载，切到夏天看地图预测，再回去与实际地面逐格比对；再从夏天切回冬天重复一次。最终包的结果：
  - 插件版 1.9.3.1：夏天 11904/11904 格一致；冬天陆地 5673/5673 格一致。
  - 插件版 1.9.5.1（两次）：夏天 11680/11680、11152/11152 格一致；冬天陆地 5522/5522、5295/5295 格一致。此前一版另加遗迹模组 2.2.0 跑过，同样全部一致。
  - 联机版 x26.07.01.01：夏天、冬天陆地均 5908/5908 格一致。
  - 冬天水面不计入：新结冰不预测（见上）。
- 触屏：往引擎触点列表里放一个不抬起的触点，再模拟拖动、双指缩放、缩放后再拖动、长按。新版在联机版、插件版 1.9.3.1、1.9.5.1 全部通过；旧版 2.7.1（插件版）复现卡死：第一次拖动后手势停在“等待全部松开”。
- 帧时间（电脑，约 144 帧上限）：换季前后中位数约 6.9 ms，多数测量段 99% 的帧 ≤ 10 ms，单帧最长一般 14～18 ms；个别一次出现 39 ms 的单帧（插件版 1.9.3.1 打开大地图换季时）。手机未实测。
- 单元测试 994/994 通过；联机包通过 `Verify-Package.ps1`。发布包与参与隔离测试的包逐字节相同。

## 发布文件

- 插件版：`[API1.9]TravelMap2.8.0.scmod`
- 联机版：`[NET]TravelMap2.8.0.netmod`

退出游戏后用新包替换旧地图包，不要同时保留两个版本。`.netmod` 放入 `NetMods`，`.scmod` 放入 `Mods`。不需要删除地图缓存、探索记录或坐标点。
